# Amadeus-Next

**Community experimental project · 社区实验性项目**

Amadeus-Next is a community experimental project hosted by Code Amadeus, currently independently maintained by [@Mieluoxxx](https://github.com/Mieluoxxx).

[**Amadeus**](https://github.com/Code-Amadeus/Amadeus) remains the main project and entry point for Code Amadeus. For this project's progress and discussions, see [this repository's issues](https://github.com/Code-Amadeus/Amadeus-Next/issues).
